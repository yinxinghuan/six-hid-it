# Six Hid It

A three-round shell game for Little 6 and the LAMOSE 4oz titanium espresso cup.

## Local development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

The Vite build uses `base: './'` so the output can run from any deployment subpath.

- `index.html` is the internal review page.
- `play.html` is the standalone public game entry.
