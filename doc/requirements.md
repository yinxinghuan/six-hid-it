# Requirements

## 1. Overview

《SIX HID IT》是一款 20–35 秒的经典三杯猜物游戏：品牌猫 Little 6 用白爪把冰花晶体藏在三只 4oz 钛杯之一并洗杯，玩家追踪并选出正确杯子，连续三轮成功后进入真实产品购买页。

## 2. Visual Design

游戏采用暖白静物摄影与黑白铜版画猫的组合。浅米白桌面、柔和自然窗光和暖银钛杯构成主体；Little 6 仅以正脸、桌边探头、眼睛、耳朵和白爪出现。产品杯使用与官网一致的圆筒比例、厚杯沿和冰花纹理，真实产品摄影用于开始与购买结算。

## 3. Game Mechanics

- 初始状态显示游戏标题、10 字以内玩法提示和“开始游戏”按钮；首次输入同时启用非阻塞 Web Audio。
- 每局包含 3 轮，首轮展示冰花晶体 1.2 秒后由杯子盖住。
- 每轮由 3 只杯子进行 3、5、7 次相邻换位，单次换位分别持续 520ms、420ms、340ms。
- 换位之间停顿 90ms；首轮开始前提供 800ms 观察缓冲。
- 玩家在洗杯完成后 5 秒内选择一只杯子；超时视为失败。
- 每轮随机选择初始藏花杯；换位只交换相邻位置，答案随实体杯移动，不在洗杯结束后重新随机。
- 猜中获得 1 枚冰花，连续三轮猜中达成 Ice Flower Complete；猜中后停留 1.1 秒进入下一轮。
- 猜错或超时显示正确杯子，停留 1.4 秒后进入失败结算；失败结算允许立即重新开始整局。
- 猫爪只负责放置晶体、推动杯子和揭晓，不遮挡杯体换位路径。
- 完成或失败结算均显示正确轮数、冰花评级、真实产品摄影、重新游戏按钮和对应购买链接。

## 4. Controls

- Pointer / Touch：洗杯完成后点击一只杯子进行选择；杯子点击区域至少 84×104 CSS px。
- Keyboard：数字键 1、2、3 选择左、中、右杯；R 重新开始。
- 洗杯阶段禁用选择并显示文字状态，避免提前点击。
- Pointer、Touch 与 Keyboard 的输入反馈在同一帧内出现；连续输入只接受第一次有效选择。

## 5. Win / Lose Conditions

- 胜利：连续猜中 3 轮，解锁 Ice Flower Complete 结算。
- 局部成功：每猜中一轮获得一枚冰花，并进入更快的下一轮。
- 失败：选错杯子或 5 秒内未选择；正确杯子抬起揭示晶体，Little 6 以耳朵转动和白爪轻推提供原因明确的反馈。
- 失败结算显示 `n / 3` 枚已获得冰花；胜利结算显示 `3 / 3` 和 Ice Flower Complete。
- 结算 CTA 跳转 `https://little6.co/products/lamose-titanium-espresso-cup-4oz-petite`，并附加游戏来源 UTM 参数。

## 6. Sound Effects

- 猫爪触桌：柔和布面拍击，80ms，音量 0.10。
- 钛杯换位：高频金属轻触 1.6–2.4kHz，50ms，音量 0.08，每次换位最多一声。
- 选择：木面轻点 180Hz，70ms，音量 0.10。
- 猜中：冰晶双音 880/1320Hz，220ms，音量 0.16，配合一次轻微触觉反馈。
- 猜错：低频木质闷响 150Hz，160ms，音量 0.12。
- 三轮完成：三音上行 523/659/784Hz，420ms，音量 0.18，叠加 70Hz、550ms 的低声合成呼噜。
