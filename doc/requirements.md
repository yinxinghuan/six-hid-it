# Requirements

## 1. Overview

《SIX HID IT》是一款 30–50 秒的经典三杯猜物游戏：品牌猫 Little 6 用白爪把冰花徽章藏在三只 4oz 钛杯之一并洗杯，玩家追踪目标，通过一次试探、二次确认揭开杯子，连续三轮成功后进入真实产品购买页。

## 2. Visual Design

游戏采用暖白静物摄影与黑白铜版画猫的组合。浅米白桌面、柔和自然窗光和暖银钛杯构成主体；Little 6 仅以正脸、桌边探头、眼睛、耳朵和白爪出现。产品杯使用与官网一致的圆筒比例、厚杯沿和冰花纹理，真实产品摄影用于开始与购买结算。

## 3. Game Mechanics

- 初始状态显示游戏标题、10 字以内玩法提示和“开始游戏”按钮；首次输入同时启用非阻塞 Web Audio。
- 每局包含 3 轮，首轮展示冰花晶体 1.2 秒后由杯子盖住。
- 每轮由 3 只杯子进行 3、5、7 次相邻换位，单次换位分别持续 520ms、420ms、340ms。
- 换位之间停顿 90ms；首轮开始前提供 800ms 观察缓冲。
- 玩家在洗杯完成后 9 秒内完成选择；第一次点击杯子触发一次完整的物理试探并将其标记为候选，第二次点击同一只杯子立即确认答案；点击其他杯子会更换候选，超时视为失败。
- 每轮随机选择初始藏花杯；换位只交换相邻位置，答案随实体杯移动，不在洗杯结束后重新随机。
- 玩家第一次轻拨时，倒扣杯必须保持杯沿贴桌并自动回正：在 420ms 内摆到约 7px / 3°，反向回摆约 3px / 1.2°，再衰减到静止。杯子回正后出现“再点确认”候选标记，不得把杯子停在倾斜状态。
- 玩家锁定选择后，Little 6 先用 180ms 压低头部并把前爪收回蓄势，再由距离答案最近的一侧用 360ms 探爪；爪垫必须实际接触正确杯身后才能触发杯子运动。
- 正确杯受爪子横向冲量后在 520ms 内离桌、旋转并第一次碰桌，再用 180ms 完成一次小回弹和金属余震；冰花在第一次碰桌后显现，而不是与选择同时出现。
- 猜中获得 1 枚冰花；正确杯第一次碰桌、冰花显现的同一时刻，画面中央显示“找到了 / 本轮 +1 冰花”的单轮结果牌。结果至少停留 1250ms，再进入下一轮；连续三轮猜中达成 Ice Flower Complete。
- 猜错或超时同样由猫爪拨开正确杯子；正确杯第一次碰桌时显示“猜错了 / 冰花在这只杯子下”或“时间到 / 冰花在这只杯子下”的单轮结果牌，至少停留 1450ms 后进入失败结算；失败结算允许立即重新开始整局。
- 猫爪的入场侧、接触点和杯子翻滚方向随答案槽位改变；待机时侧边必须可见约 68–76px、高约 56px 的连续前腿，其中靠画外一段是约 18–24px 深棕袖身，前端约 54–58px、高约 48px 为白色“手套”爪。轻拨时继续伸长约 45–60px。右侧答案优先使用右爪，避免爪子脱离身体横穿全屏。
- 猫头本身是独立动作层：390px 画面使用约 360px 宽的等比猫头，常态下缘被桌面遮住约 42px；320px 画面使用约 310px 宽的等比猫头，下缘被桌面遮住约 36px。待机时以 2.8 秒周期上下呼吸约 9px；放置和遮盖时下沉 38–44px；洗杯时以 1.4 秒周期在 30–44px 低位跟踪；进入选择时用 520ms 探出并以 1.9 秒周期起伏约 14px；每次轻拨时额外上探约 16px，揭晓前再下压 7px 蓄势。
- 碰撞反馈包含爪垫压缩、杯身起转、桌面接触环、2–3 条短促冲击线和一次轻微画面震动；不使用与杯体绑定的假投影或漫天粒子。
- 揭晓物是一枚具有正面、侧切面、厚度和桌面投影的六瓣冰花实体徽章，中心压印 `LITTLE 6` 标识。
- 完成或失败结算均显示正确轮数、冰花评级、真实产品摄影、重新游戏按钮和对应购买链接。

## 4. Controls

- Pointer / Touch：洗杯完成后点击一只杯子进行物理试探；第一次使其贴桌滑移、回正并标记为候选，第二次点击同一只杯子确认并触发物理揭晓。中途点击另一只杯子会移除前一候选并重新试探。
- Keyboard：数字键 1、2、3 分别试探左、中、右杯；同一数字键第二次有效触发时确认，R 重新开始。
- 洗杯阶段禁用选择并显示文字状态，避免提前点击。
- Pointer、Touch 与 Keyboard 的输入反馈在同一帧内出现；杯子回正前锁定输入，回正后立即接受确认或换杯，避免动画状态重叠。

## 5. Win / Lose Conditions

- 胜利：连续猜中 3 轮，解锁 Ice Flower Complete 结算。
- 局部成功：每猜中一轮获得一枚冰花，并进入更快的下一轮。
- 失败：确认错误杯，或 9 秒内未完成选择；Little 6 从侧后方拨翻正确杯，揭示带品牌标识的冰花徽章。
- 失败结算显示 `n / 3` 枚已获得冰花；胜利结算显示 `3 / 3` 和 Ice Flower Complete。
- 结算 CTA 跳转 `https://little6.co/products/lamose-titanium-espresso-cup-4oz-petite`，并附加游戏来源 UTM 参数。

## 6. Sound Effects

- 猫爪蓄势：柔和布面摩擦，90ms，音量 0.08。
- 爪垫撞杯：`760 / 1860 / 3380 / 5740Hz` 四个非整数倍模态，80–260ms 分层衰减，叠加 3.2kHz、22ms 接触噪声，音量峰值 0.12。
- 杯子第一次碰桌：`620 / 1680 / 3150 / 5420Hz` 四个钛杯模态，160–480ms 分层衰减，叠加 2.4kHz、28ms 冲击噪声；随后 70ms 与 145ms 各追加一次递减高频余震，音量峰值 0.15。
- 钛杯换位：使用 `1120 / 2860 / 4380Hz` 三个非谐振模态，45–110ms 分层衰减，叠加 2–6kHz、18ms 带通噪声瞬态；每次换位最多一声。
- 所有金属合成通过共享动态压缩器输出，阈值 `-18dB`、ratio `5:1`、attack `3ms`、release `180ms`，避免移动扬声器削波和刺耳峰值。
- 选择：木面轻点 180Hz，70ms，音量 0.10。
- 猜中：冰晶双音 880/1320Hz，220ms，音量 0.16，配合一次轻微触觉反馈。
- 猜错：低频木质闷响 150Hz，160ms，音量 0.12。
- 三轮完成：三音上行 523/659/784Hz，420ms，音量 0.18，叠加 70Hz、550ms 的低声合成呼噜。
