# Screen Contract

## 全局环境

- 类型：响应式评审页 + 9:16 固定比例游戏切片。
- 目标：320×568、390×844、1440×980。
- 输入：Pointer、Touch、数字键 1/2/3 与 R。
- 安全区：游戏 HUD 顶部 64px，选择提示底部 96px。

## Game Entry

- 玩家问题：我要做什么、如何开始？
- 主焦点：Little 6、三只 4oz 钛杯与冰花标题印章。
- 主操作：开始游戏。
- 次操作：无；购买入口留到结算，避免分散注意。
- 恢复：开始按钮保持 44px 以上，键盘 Enter / Space 可触发。

## Place / Cover

- 玩家问题：冰花被哪只实体杯盖住？
- 主焦点：目标杯、冰花和白爪。
- 主操作：观察；三只杯禁用。
- 临时反馈：目标杯抬起、冰花出现 1.2 秒后落杯遮盖。

## Shuffle

- 玩家问题：装着冰花的杯子移动到哪里？
- 主焦点：相邻杯的换位轨迹。
- 主操作：追踪；三只杯禁用。
- 持久信息：轮次与已获得冰花。
- 临时反馈：每次交换伴随金属轻触，状态显示 WATCH SIX。

## Choose

- 玩家问题：冰花现在在哪只杯子下面？
- 主焦点：三只落定钛杯和 9 秒选择计时线。
- 主操作：连续轻拨同一只杯子 3 次，或连续按对应数字键 3 次；中途可改拨另一只并重新累计。
- 持久信息：轮次、三枚冰花进度。
- 临时反馈：猫从洗杯时的 32px 低位探出；第一次轻拨产生猫头上探 9px 与杯子 5px / 2° 阻尼摇晃，第二次产生同样的探头动作和杯子 9px / 4° 阻尼摇晃；两次均在 420ms 内自动回正。猫眼、瞳孔和眉毛随目标与力度变化，侧边常驻白爪尖只增加伸出长度。只有第三次有效轻拨才锁定全部杯。
- 恢复：R 或 RESET 重新回到游戏开始状态。

## Reveal

- 玩家问题：我选对了吗？
- 主焦点：猫眼锁定目标、侧后方白爪逐级拨歪杯子，第三次将正确杯翻滚碰桌并露出 `LITTLE 6` 冰花徽章。
- 主操作：等待 1.1–1.4 秒。
- 临时反馈：第一次轻拨贴桌滑移，第二次进一步拨歪；第三次才确认。猜中显示品牌冰花徽章与猫点头；猜错将错误杯降饱和并由猫拨开正确杯。

## Complete Result

- 玩家问题：我完成了什么、产品在哪里买？
- 主焦点：3 / 3 冰花、真实产品摄影和完成印章。
- 主操作：查看 4oz 钛杯。
- 次操作：再玩一次。
- 恢复：R 或再玩一次立即重开。

## Failed Result

- 玩家问题：我找到了几枚、如何再试？
- 主焦点：n / 3 冰花与正确答案说明。
- 主操作：再试一次。
- 次操作：查看 4oz 钛杯。
- 恢复：R 或再试一次立即重开。

## 组件状态

| 组件 | 默认 | Pressed/Focus | 禁用 | 成功 | 失败 |
|---|---|---|---|---|---|
| 钛杯 | 桌面落定 | 第一次 5px / 2° 摇晃、第二次 9px / 4° 摇晃，均自动归零 | 放置与洗杯时不可点 | 第三次触发翻滚、碰桌、回弹 | 错杯降饱和、正确杯执行同一物理揭晓 |
| START / RETRY | 纸白实心按钮 | 下沉 2px / 可见焦点环 | 状态切换时禁用 | 开始下一局 | 重开整局 |
| RESET | 安静文字 | 可见焦点环 | 无 | 返回开始 | 返回开始 |
| 状态文案 | FIND THE FLOWER | — | WATCH SIX | YOU FOUND IT | SIX FOOLED YOU / TIME |
| 计时线 | 隐藏 | — | 放置与洗杯时隐藏 | 选择后冻结 | 超时归零 |
